# Task Changelog

## 2026-08-20 — Migrate aura.ts/aura-digest.ts to AuraClient; dedupe types.ts (call-site-migration)
Migrated `scripts/src/aura-digest.ts` + `scripts/src/aura.ts` from `McpClient.callTool` to the typed `AuraClient` interface via `createDefaultAuraClient()` (all 21 exercised Aura verbs). Dropped `REQUIRED_TOOLS`/`assertToolsAvailable`/all Aura `client.close()` calls; kept the Atlassian `McpClient` path in `devlinks.ts` (out of scope). Added `dbus-next` to the esbuild `external` array (transitive keyring dep with an optional `x11` require). Removed 20 hand-maintained Aura-response shapes from `scripts/src/types.ts` (now single-sourced in `@pi-aura/shared/aura-client`); retyped embedded references (`RawAuraData`, `DigestReview.decisions`, `ArtifactVerification.current`, `fetchTaskDevLinks`) to domain types; kept the digest/report/diff/dev-link types. Field renames: Artifact `current_version`→`latest_version`, KnowledgeNode `uuid`→`id`/`version`→`latest_version`, UploadDocument pages `text`→`content`. Outcome: the scripts' Aura path is MCP-wrapper-free and the types are single-source — `clients-cleanup` can now remove `bearerClient`'s Aura path + the dead `scripts/src/generated/` tree + `scripts`' `@hey-api/*` deps.

## 2026-08-20 — AuraClient interface + HeyApiAuraClient impl + createDefaultAuraClient() factory (aura-client)
Moved the `@hey-api` REST codegen from `scripts/` into `packages/shared/` (single-source generated client, `@hey-api/client-fetch` runtime dep, `make codegen` target repointed). Added an implementation-agnostic `AuraClient` interface (21 exercised verbs) with expressive domain types in `@pi-aura/shared/aura-client` — no generated types leak into the interface (Q8). Implemented `HeyApiAuraClient` (delegates to the generated SDK, maps domain<->generated internally, `Authorization: Bearer <PAT>` from the keyring, throws `AuraApiError` on SDK errors) + `createDefaultAuraClient()` factory (reads `aura.baseUrl` from settings.json, builds the keyring, validates the PAT). 4 `tsx --test` smoke tests pass; `scripts/` untouched (rewiring is the next task). Outcome: the shared `AuraClient` layer is ready for `call-site-migration` to drop the MCP wrapper from the scripts path.
